# vd3-token-ci-hygiene

## Why

A documentation-and-tooling audit found stale or inaccurate prose in the
token/CSS comments, config, and README, one dead CSS-class attribute on a
component, an undocumented build invariant, and a CI workflow missing a
dependency-audit gate and pnpm caching. None change runtime behavior; they keep
the repo's self-description honest and harden CI.

1. **Palette comments credit the wrong default and the old repo.**
   `css/core/colors.css` and `css/vd3.css` say the default palette is Fibonacci
   and that the partials are "generated by `@vanduo-oss/core`". Both are wrong:
   Open Color is the default (Fibonacci opts in via `data-palette="fibonacci"`),
   and the partials are generated by this repo's `scripts/build-tokens.mjs`.
2. **`dist/tokens.json` `$description` overclaims completeness.** It reads as the
   full resolved `--vd-*` set, but non-color props (`--vd-glass-*`,
   `--vd-transition-*`, `--vd-z-*`, `--vd-font-family-*`) ship only from the
   hand-authored `css/core/tokens.css`, and `css/core/tokens.css` still carries a
   stale `v1.4.1` header.
3. **`openspec/config.yaml` says "Fonts (10 families)"** but 11 ship.
4. **`VdThemeCustomizer`'s Reset button carries dead `btn btn-sm btn-outline`
   classes** (no vd3 selector); it is already fully styled via `.customizer-reset`.
5. **The `emptyOutDir: false` invariant is undocumented.** Nothing near it in
   `vite.config.ts` records that no SFC may carry a `<style>` block (which would
   make plugin-vue emit an unreferenced style asset that accumulates in `dist/`).
6. **README duplicates the full per-group inventory** (SKILL.md owns it) and
   lists internal OpenSpec slugs (`vd3-rewrites`/`vd3-new-components`/
   `vd3-hardening`) in the Status line.
7. **`.npmrc` prose enumerates legacy package names** (core, framework, vd2) in
   the scope-exclude comment.
8. **CI lacks a dependency audit and pnpm caching.** `ci.yml` runs no
   `pnpm audit`, and its `setup-node` has no `cache: pnpm`.

## What Changes

Comment/doc/config/CI-only edits plus one security override; no source logic and
no public API changes.

- **`css/core/colors.css` / `css/vd3.css`** — fix the palette comments (Open
  Color default, Fibonacci opt-in via `data-palette="fibonacci"`) and replace
  `@vanduo-oss/core` with `scripts/build-tokens.mjs`.
- **`scripts/build-tokens.mjs`** — soften the `dist/tokens.json` `$description`
  so it no longer claims to be the complete `--vd-*` set.
- **`css/core/tokens.css`** — drop the stale `v1.4.1` header comment.
- **`openspec/config.yaml`** — `Fonts (10 families)` → `Fonts (11 families)`.
- **`src/components/VdThemeCustomizer.vue`** — remove the dead `btn btn-sm
  btn-outline` classes from the Reset button (keep `class="customizer-reset"`).
- **`vite.config.ts`** — document the `emptyOutDir: false` / no-SFC-`<style>`
  invariant in a comment beside it.
- **`README.md`** — trim the duplicated per-group inventory to a counts-level
  overview (SKILL.md owns the full list), and reduce the Status section to a
  single `Status: 1.0.0 — first public release` line (drop the internal slugs).
- **`.npmrc`** — reword the scope-exclude comment to "all @vanduo-oss
  first-party publishes" (the functional line is unchanged).
- **`.github/workflows/ci.yml`** — add `cache: pnpm` to `setup-node` and a
  `pnpm audit --audit-level=moderate` step after install.
  **`pnpm-workspace.yaml`** — add dev-only security `overrides` pinning the
  flagged transitive `brace-expansion` (GHSA-3jxr-9vmj-r5cp) and `fast-uri`
  (GHSA-v2hh-gcrm-f6hx) to patched releases so the audit gate is green.

## Non-goals

- **No runtime behavior change.** No component logic, prop, emit, slot, `vd-*`
  class, `--vd-*` custom property, token *value*, or `localStorage` contract
  changes. The `tokens.json` change is to its `$description` string only; token
  *values* are untouched.
- **No token sync-gate.** Asserting that every `--vd-*` custom property in
  `css/core/tokens.css` is represented in `dist/tokens.json` is out of scope —
  noted as a follow-up. This change only stops the description from overclaiming.
- No new components, composables, exports, tokens, or runtime dependencies.
- No changes to the old repos (core, framework, vue, vd2, satellites); no
  docs-site content (`vd3-docs`).

## Impact

- Package: `@vanduo-oss/vd3`. **Semver: patch** — housekeeping + CI hardening;
  the only shipped-artifact change is the `dist/tokens.json` `$description`
  string and the `VdThemeCustomizer` markup (dead-class removal, visually inert).
- API compatibility (vd2 → vd3): none affected — no public surface changes.
- Build/test: build chain unchanged. Adding the `brace-expansion` and `fast-uri`
  `overrides` updates the lockfile (dev-only; never shipped in `dist/`) and makes
  `pnpm audit --audit-level=moderate` report no known vulnerabilities.
- Docs: none in this change (docs-site prose is governed by `vd3-docs`).
- Changelog: unreleased `@vanduo-oss/vd3` "Changed" entries for the shipped
  edits (VdThemeCustomizer dead-class removal, tokens.json `$description`); the
  CI/README/comment edits are repo-meta, not package-changelog items.
